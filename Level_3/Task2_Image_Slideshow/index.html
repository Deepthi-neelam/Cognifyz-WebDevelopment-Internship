⚙️ How It Works

CSS Keyframes: @keyframes slideShow controls the visibility of each slide

Animation Delay: Each slide has staggered animation-delay (0s, 5s, 10s, etc.)

Infinite Loop: animation-iteration-count: infinite creates seamless loop

Opacity Control: Slides fade in and out using opacity property
