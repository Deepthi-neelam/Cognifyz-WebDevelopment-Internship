## 🎞️ Level 3 - Task 2: CSS Image Slideshow

### 📁 Location: `Level_3/Task2_Image_Slideshow/`

An automatic image slideshow built with pure CSS animations.

**Features:**
- 🔄 5-image automatic slideshow
- ⏱️ 5-second transition between images
- 🎯 CSS keyframes animation (no JavaScript)
- 🔘 Synchronized navigation dots
- 📝 Image captions with hover effects
- 📱 Fully responsive design

**Technical Details:**
- Total cycle time: 25 seconds (5 slides × 5 seconds each)
- Each slide: 1s fade in + 3s visible + 1s fade out
- Perfectly synchronized with navigation dots

**Key Technologies:** HTML5, CSS3 (Keyframes, Animations)

**Files:**
- `index.html` - Slideshow structure
- `style.css` - CSS animations and styling
